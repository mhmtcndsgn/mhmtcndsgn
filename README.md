# Mehmet Can Dusgun

**Mechatronics Engineering student · Embedded systems · Hardware & PCB design**

I'm a senior Mechatronics Engineering student at **Istanbul Health and Technology University (İSTÜN)**, graduating in 2027.
I like building things end to end: the circuit, the firmware that runs on it, and the desktop tool that reads its data.
My main interests are embedded systems, sensor signal processing and medical / wearable devices.

### Featured project

**[Oskilo](https://github.com/mhmtcndsgn/Oskilo)**: a lossless serial data logger for STM32, Arduino and ESP32.
Live chart, CRC-protected binary frames, threshold alarms, FFT and export to Excel / CSV. Windows and macOS builds.

### Projects

|---|---|---|
| **Elderly monitoring watch** *(senior design, in progress)* | Wrist-worn device that detects emergencies, sends an SMS with location to relatives, calls 112 and shares live pulse and respiration data over GSM. | Embedded C, GSM/GNSS, biosignals |
